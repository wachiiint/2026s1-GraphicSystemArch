# LAB1 — TinyVGAPlayground

## Description
I will do very simple flappybird game in this project

## Manual
[Open LAB1 in VGA Playground](https://vga-playground.com/?repo=https://github.com/wachiiint/2026s1-GraphicSystemArch&ref=submit-lab1), then select **Gamepad** input mode.

To run locally:
- Run `npm start` in `vgaEngine/`
- Open `localhost:5173` in browser
- Change input on top right to gamepad mode
- Press arrow key up to start playing !
