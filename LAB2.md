# LAB2 — Try hard Text Editor

## Description
An ancient text editor with very not-intuative input \
Inspired by pokemon essentials text input

## Manual
- Run `npm start` in `vgaEngine/`
- Open `localhost:5173` in browser
- Change input on top right to gamepad mode
- Press A to type, B to erase
- Press X, Y to change character (sort by ASCII code)
- Press L for new line and R for space
- Arrow in all direction to move cursor
